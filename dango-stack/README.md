# 团子叠叠乐

手机上玩的可爱卡通方块消除游戏。七种方块是七只团子：猫、小鸡、兔子、青蛙、小猪、企鹅、狐狸。下落时会眨眼，落定后眯眼睡觉，叠得太高会冒冷汗，消行时开心大笑。

整个游戏就是一个网页，画面和音效都由代码生成，没有图片和音频素材。

## 怎么玩

用手机浏览器打开 `index.html` 所在的网址即可。棋盘铺满整个屏幕。

| 操作 | 手势（屏幕上任意位置） | 键盘 |
| --- | --- | --- |
| 移动 | 左右滑 | ← → |
| 旋转 | 轻点 | ↑ 或 X（Z 反向） |
| 加速下落 | 下滑 | ↓ |
| 直接落地 | 快速下划 | 空格 |
| 暂存，换一只 | 上滑，或点左上角“暂存” | C |
| 暂停 | 右上角按钮 | P |

不习惯手势的话，在开始或暂停面板里把“按键”打开，屏幕底部会出现一排按钮。

规则：10×20 棋盘，七只一袋随机，落点预览，预告三只。消 1/2/3/4 行得 100/300/500/800 × 等级，连击加分，每消 10 行升一级并加速。最高分存在当前浏览器里。

## 在 iPhone 上全屏玩

iPhone 的 Safari 不允许网页自己进入全屏，要这样做：

1. 用 Safari 打开游戏网址
2. 点分享按钮，选“添加到主屏幕”
3. 从主屏幕上的图标打开

这样打开就没有地址栏和工具栏，棋盘占满整个屏幕；打开过一次之后断网也能玩。

安卓和电脑浏览器可以直接点面板里的“全屏”。

## 文件

- `index.html`：游戏本体（样式和程序都在里面）
- `manifest.json`、`icons/`：添加到主屏幕时用的名称和图标
- `sw.js`：离线缓存
- `tools/make-icons.py`：重新生成图标（需要 playwright 和 Chrome）

改了游戏后，把 `index.html` 里的 `VERSION` 和 `sw.js` 里的 `CACHE` 一起改掉，开始面板底部会显示版本号。
